   - Remove `--force`. (At `7a9e315`, `run_pi.sh` launches `fly` as `drone_dispatch.py --fly --force`, which flies with `DRONE_DRY_RUN` still True. SW-00 removes that `--force` from the launcher; this draft finishes the job in the dispatcher.) Live flight then requires both `--fly` and a human-edited `DRONE_DRY_RUN = False`.

1b. Draft a patch for the `fly` branch of `run_pi.sh`, applied by a human because it is a flight path: no `--force`, and a typed confirmation read from the terminal, refused when stdin is not a terminal.
2. Draft new tests for what can be tested without hardware. Pin `cflib` to the version HW-C1 used, as a draft.
