## Scope
In `run_pi.sh`, change the `fly` branch from `drone_dispatch.py --fly --force` to `drone_dispatch.py --fly`. Nothing else. With the pinned `DRONE_DRY_RUN = True` the dispatcher then
refuses to fly and says so. (`--force` made a real flight possible while the config said dry-run. This is an unprotected launcher, so a builder makes this edit; nobody edits it by hand.)

## Explicit exclusions
No change to `pi/drone_dispatch.py` (protected; SW-08). No change to any config value. No flight.
