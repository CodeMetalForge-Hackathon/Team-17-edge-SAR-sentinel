## Scope
1. `Brain.on_scan` keeps `ts`. New `config.SCAN_MAX_AGE_S = 2.0`. Stale or absent range means no position.
2. When a person cannot be placed, publish a rate-limited `forge/status` WARN (at most once per 5 s). No event.
3. `Brain(bus, model, nodes=None)`: `None` uses `config.NODES`. Accept `{id: (x, y)}` or `{id: {"x":..., "y":...}}`. `{}` means no nodes.
4. A camera person within new `config.BEACON_NEAR_M = 1.0` of the nearest node passes that node to `decide()`, so `BEACON` fires. `simulate.py` and `dashboard.py` pass `SIM_NODES` to the brain, since sim has its own n2.
5. The cooldown key adds the sorted action names, so a changed decision is not suppressed and an identical one still is.

## Explicit exclusions
No `decide()` rule changes. No routing. No baseline-aware range selection (log any need in HW-D1).
