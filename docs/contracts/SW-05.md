## Scope
1. `config.DEMO_REGION`: `None` or a polygon in map metres. Default `None`. The real polygon is measured in HW-D1.
2. In `Brain`: person and LiDAR events outside the region produce an INFO status and no event. **Node hazards are never filtered.**
3. `config.OBSTRUCTION_HOLD_S = 2.0`. `on_change` holds a change. `on_scan`, using the scan's `ts`, releases it after the hold time unless a person fix landed near it. `0` fires at once, and `simulate.py --local` uses 0 as it already does for its cooldown. Reset clears held changes.
4. Reason text: replace "possible collapse" with wording that says stability is not assessed. The `STRUCTURAL` kind stays.
5. Dashboard: draw the region; show `SURVIVOR` as "possible survivor"; the structure label says "vibration, stability not assessed". Event kinds on the bus do not change.

## Explicit exclusions
No renamed event kinds. No filtering of flame or water. No camera-side filtering.
