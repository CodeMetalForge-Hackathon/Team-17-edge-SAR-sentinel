## Scope
1. **Firmware.** Count a vibration only on an inactive-to-active transition, ignoring further edges for `VIB_REFRACTORY_MS` (start at 50, a bench value).
2. **Firmware.** Turn the LED off once when a beacon ends. Do not interfere with the `A` ack blink.
3. **Sim.** `node_window("tap")` totals 1 to `VIB_STRUCTURAL - 1` events. `shake` gives at most 2 per reading and at least `VIB_STRUCTURAL` per window.
4. **Features.** Add `FEATURE_SEMANTICS_VERSION = 2`. `FEATURE_NAMES` stays the same.
5. **Model.** `save` records `feature_semantics`. `load` raises new `anomaly.ModelSchemaError(ValueError)` on missing or different semantics or a feature mismatch.
6. **Brain.** `main` treats `ModelSchemaError` as no model, with a clear message.
7. **Docs.** In `bus.py` and README, state that serial `vib` and feature `vib_hits` count distinct events. Fix the `sources` doc to `source`.

**Reference for scope item 1** (adapt, not authoritative):

```cpp
bool vibNow = digitalRead(PIN_VIB) == VIB_ACTIVE;
if (vibNow && !vibPrev && millis() - lastVibEdge >= VIB_REFRACTORY_MS) { vibHits++; lastVibEdge = millis(); }
vibPrev = vibNow;
```
