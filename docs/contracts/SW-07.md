## Scope
1. `pi/hailo_person_app.py` has pure `persons_from_detections(dets)`, returning `(cx_norm, conf)` for `person` labels using `get_label`, `get_confidence`, `get_bbox`, `xmin` and `width`.
2. `app_callback(element, buffer, user_data)` follows [hailo-apps detection.py](https://github.com/hailo-ai/hailo-apps/blob/main/hailo_apps/python/pipeline_apps/detection/detection.py): `hailo.get_roi_from_buffer(buffer)`, then `roi.get_objects_typed(hailo.HAILO_DETECTION)`. Any `hailo` or `hailo_apps` import stays inside functions.
3. `main()` uses `GStreamerDetectionApp(app_callback, user_data)`.
4. `PersonPublisher.publish_many(list)`: same payload per person; rate limit applies per batch; `publish` keeps working.
5. Update the `hailo_hook.py` docstring and `THIRD_PARTY.md` ("we only edit its callback" becomes "we import its pipeline").
