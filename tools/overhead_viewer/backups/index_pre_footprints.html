Manual rover control

Corner order: BL=(0,0) green, BR=(1,0) blue, TR=(1,1) orange, TL=(0,1) magenta (as seen in the image). Cells: letter = column left→right, number = row bottom→top (A1 is bottom-left). Coordinates are dimensionless 0–1 fractions of the boundary; they are not metres. Lens distortion is NOT corrected, so the mapping is only approximately straight-line accurate, worse toward image edges. Marker detection is manual here (no auto-detect). Rover forward direction and conventions are UNVERIFIED until tested on hardware. Clearance is a count of grid cells; rover dimensions are unknown, so it is not a physical clearance guarantee. Each move needs a fresh photo and re-set pose. Route preview: static A* over a manually labelled 4-connected grid. Blocked cells are hand-marked, not detected. It is not a physically safe route, ignores rover size, and is not a motor command.
